# End Semester - Coding Assignment

This is End Semester - Coding Assignment 

## Tasks

1. Go through the assignment description PDF in this repository
2. Complete the codes for the three problems
3. Design the encoding, devise the heuristics, and do the reward shaping as required. 
4. Write a brief summary about your learnings from each problem, in the report.txt. Limit to 200 words for each problem
5. Submission - after completion of your code, commit it to your repository. Ensure frequent, incremental submissions.
The final submission before deadline will be used for testing.
6. The completed code will be used for inference. Make sure that it follows the same structure as given in template, to be able to read and use. 

Do **not** modify test files or any other files, except the ones in src/.
Do **not** import ML packages like sklearn, statsmodels, PyTorch, TensorFlow etc. to solve the problem.
You can complete the code with packages already present.
